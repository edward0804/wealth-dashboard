☁️ 30 秒建好我的 Google Sheet（Apps Script ＋ 一鍵初始化）
零寫死試算表 ID 與股票清單：任何人只要貼進自己同格式的 Google Sheet，就會自動綁定對方的試算表！
步驟 1：一鍵複製兩個檔案到試算表的「擴充功能 → Apps Script」
  1. 打開任意一個 Google Sheet（全新空白試算表或你自己的既有試算表皆可），點上方選單 擴充功能 (Extensions) → Apps Script。
  2. 點左側「檔案」旁的 ＋ → 指令碼，命名為 Dashboard（若為全新空白專案也可直接貼在預設的 程式碼.gs），點擊下方按鈕複製貼上 Code.gs。
  3. 再點左側「檔案」旁的 ＋ → HTML，命名為 Index（系統會自動變成 Index.html，注意 I 大寫），清空預設內容後點擊下方按鈕複製貼上 Index.html，按 Cmd+S 儲存。
  4. 若你是全新空白試算表：回到試算表按 F5 重新整理後，點上方選單 「📊 財務儀表板 → 🚀 一鍵初始化標準帳本結構」，系統會自動建好所有工作表標題、範例列與 SUMIFS / GOOGLEFINANCE 公式（已含資料的分頁會自動略過，絕不覆蓋）！
步驟 2：部署雲端網頁應用程式（同時支援電腦全螢幕 & iPhone 獨立 App API）
  1. 在 Apps Script 右上角點 部署 (Deploy) → 新增部署作業 (New deployment)（若先前已部署過，點「管理部署作業 → ✏️ 編輯 → 建立新版本」）。
  2. 左上角齒輪選取類型：網頁應用程式 (Web app)，執行身分選 「我 (Me)」。
  3. 存取權限選擇：
    • 若要配對 📱 iPhone 主畫面全螢幕獨立 App：請選 「所有人 (Anyone)」（Code.gs 已內建 256-bit 私密配對金鑰驗證，無配對碼者完全無法讀取或修改任何資料！）。
    • 若只在電腦瀏覽器開網址、不裝獨立 App：可選「僅限我自己 (Only myself)」。
  4. 部署完成後回到 Google Sheet 重新整理，點上方選單 「📊 財務儀表板 → 📱 取得 / 重設 iPhone App 專屬配對碼」 即可一鍵複製配對碼！若需要每日自動淨值走勢圖，也可點選 「⏰ 開啟 / 關閉每日淨值紀錄排程」。
💡 給不同使用者的彈性啟動小撇步：
• 沒有試算表、想從零開始：開一份空白 Google Sheet → 貼上兩份檔案 → 點選 「🚀 一鍵初始化標準帳本結構」，30 秒完成開帳，並支援在既有欄位移位／新增自訂欄位後自動以標題列對應！
• 有多位使用者想各自記帳：所有人都可共用同一個前端 App 網址，各自在自己的 Google Sheet 部署相同程式碼，貼上自己的 WDB1:... 配對碼即可獨立連線使用！
📲 安裝成全螢幕無邊框 App：點下方 Safari 「分享 ⬆️ → 加入主畫面」，即可從桌面秒開且隱藏網址列！

🚀 3 分鐘把完整無邊框 App 裝進 iPhone 主畫面（支援空白試算表一鍵建表）：
  1. 建立或連線試算表雲端 API：將 Code.gs 與 Index.html 貼入 Google Sheet 的 Apps Script（若為全新空白試算表，可先點選單 「🚀 一鍵初始化標準帳本結構」），點「部署 → 管理部署作業 → 新版本」，設為 執行身分：我 (Me)、誰可以存取：所有人 (Anyone)，再從試算表上方選單複製 WDB1:... 配對碼。
  2. 免費發布純前端 App 外殼（零個資上傳）：在電腦終端機執行 vercel --prod（專案已內建 .vercelignore 嚴格排除本地資料），或將 public/ 資料夾放到 GitHub Pages / Netlify，取得專屬 https://... 網址（多位使用者可共用同一個 App 網址，各自配對自己的試算表！）。
  3. 加入 iPhone 主畫面：用 iPhone Safari 打開該網址 → 點底部 「分享 ⬆️ → 加入主畫面」 → 從 iPhone 桌面點開專屬貓咪抱錢圖示 App → 按上方 「📋 一鍵貼上配對碼」 即完成永久綁定！
