☁️ 轉成 Google Apps Script（支援多人／同格式試算表通用）
零寫死試算表 ID 與股票清單：任何人只要貼進自己同格式的 Google Sheet，就會自動綁定對方的試算表！
步驟 1：一鍵複製兩個檔案到試算表的「擴充功能 → Apps Script」
  1. 打開你的（或女友的）Google Sheet，點上方選單 擴充功能 (Extensions) → Apps Script。
  2. 點左側「檔案」旁的 ＋ → 指令碼，命名為 Dashboard（獨立新增檔案最安全，不會覆蓋你原本用來每日自動記錄《歷史紀錄》的腳本；若為全新空白專案也可直接貼在預設的 程式碼.gs），點擊下方按鈕複製貼上 Code.gs。
  3. 再點左側「檔案」旁的 ＋ → HTML，命名為 Index（系統會自動變成 Index.html，注意 I 大寫），清空預設內容後點擊下方按鈕複製貼上 Index.html，按 Cmd+S 儲存。
步驟 2：部署雲端網頁應用程式（同時支援電腦全螢幕 & iPhone 獨立 App API）
  1. 在 Apps Script 右上角點 部署 (Deploy) → 新增部署作業 (New deployment)（若先前已部署過，點「管理部署作業 → ✏️ 編輯 → 建立新版本」）。
  2. 左上角齒輪選取類型：網頁應用程式 (Web app)，執行身分選 「我 (Me)」。
  3. 存取權限選擇：
    • 若要配對 📱 iPhone 主畫面全螢幕獨立 App：請選 「所有人 (Anyone)」（Code.gs 已內建 256-bit 私密配對金鑰驗證，無配對碼者完全無法讀取或修改任何資料！）。
    • 若只在電腦瀏覽器開網址、不裝獨立 App：可選「僅限我自己 (Only myself)」。
  4. 部署完成後回到 Google Sheet 重新整理，點上方選單 「📊 財務儀表板 → 📱 取得 / 重設 iPhone App 專屬配對碼」 即可一鍵複製配對碼！
💡 給女友使用的超省力小撇步：
• 若女友已經有自己的同格式試算表：請她在她的試算表打開「擴充功能 → Apps Script」，貼上完全相同的這兩份檔案並部署即可（不需改任何一行程式碼，她的 iPhone App 配對她的配對碼就會連到她的試算表！）。
• 若想直接給她模板開始記帳：在你的試算表裝好 Apps Script 後，複製一份清空數字的模板給她按 「檔案 → 建立副本」，Google 會連同裡面的 Apps Script 程式碼一起自動複製過去！
